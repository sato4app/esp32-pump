## esp32-pump - ESP32からポンプを制御

ESP32-C3からポンプを制御するWebアプリ

現在は、スイッチとLEDの動作確認用のサンプルファームウェアのみ（ポンプはまだつながない）。

## 動作確認サンプル

- タクトスイッチを押すたびに、外付けLEDの点灯・消灯を切り替える
- 電源モジュールから給電するとシリアルモニタが使えないため、状態をLEDで表す

| 表示 | 意味 |
|---|---|
| 起動時、外付けLEDがゆっくり3回点滅 | 通常の起動 |
| 起動時、外付けLEDが速く10回点滅 | 電圧低下でリセットした（ブラウンアウト）。電源を見直す |
| 基板上のLEDが0.5秒ごとに点滅 | プログラムが動いている |
| 基板上のLEDが点滅しない | 電源が来ていない、またはプログラムが止まっている |

- USBでつないでいるときは、シリアルモニタ（115200bps）に起動の理由と「LED: 点灯」「LED: 消灯」を表示する

## 構成

| 部位 | 部品 | 備考 |
|---|---|---|
| マイコン | ESP32-C3 Super Mini | PlatformIOのボード設定は `esp32-c3-devkitm-1` |
| モータードライバ | TB6612FNG モジュール | 今回は未使用（ポンプ制御で使う予定） |
| 電源 | 電源モジュール | ESP32へ5Vを供給する場合に使う。USB給電だけでも動く |
| スイッチ | タクトスイッチ | |
| LED | LED ＋ 330Ω抵抗 | |

## 配線

「現在」は電源モジュールのテスト用の配線、「ポンプ追加後」はTB6612FNGでポンプをつないだときの予定。
ピン番号を変えたときは `firmware/src/config.h` と合わせて直す。

### ESP32-C3 Super Mini

| 端子 | 現在の接続先 | ポンプ追加後の接続先 | 備考 |
|---|---|---|---|
| 5V | 電源モジュールの5V出力 | 同じ | USBと同時につながない |
| GND | 電源モジュールのGND、スイッチ、LED | 同じ ＋ TB6612FNG GND | GNDはすべて共通にする |
| 3V3 | — | TB6612FNG VCC | TB6612FNGのロジック電源 |
| GPIO0 | — | — | 空き |
| GPIO1 | — | — | 空き |
| GPIO2 | — | — | 起動モードを決めるピンなので使わない |
| GPIO3 | タクトスイッチ（もう片側はGND） | 同じ | 内部プルアップを使うので抵抗は不要 |
| GPIO4 | — | TB6612FNG AIN1 | ポンプの回転方向1 |
| GPIO5 | — | TB6612FNG AIN2 | ポンプの回転方向2 |
| GPIO6 | — | TB6612FNG PWMA | ポンプの出力（PWM） |
| GPIO7 | 330Ω → LEDの長い足（短い足はGND） | 同じ | ポンプ追加後は運転表示にする予定 |
| GPIO8 | 基板上のLED（外部には何もつながない） | 同じ | 動作中の点滅表示。起動モードを決めるピン |
| GPIO9 | — | — | BOOTボタン。起動モードを決めるピンなので使わない |
| GPIO10 | — | TB6612FNG STBY | LOWにするとポンプを切り離す |
| GPIO20 | — | — | 空き（UART RX） |
| GPIO21 | — | — | 空き（UART TX） |

GPIO18/19は基板内でUSB（書き込み・シリアル）に使われているため、端子には出ていない。

### TB6612FNG（ポンプ追加後）

| 端子 | 接続先 | 備考 |
|---|---|---|
| VM | 電源モジュールの出力＋ | ポンプ用の電源。VMとGNDの間、端子の近くに電解コンデンサを入れる |
| VCC | ESP32 3V3 | |
| GND | 共通GND | モジュールにGND端子が複数あれば、すべてつなぐ |
| AIN1 / AIN2 / PWMA | GPIO4 / GPIO5 / GPIO6 | |
| STBY | GPIO10 | |
| AO1 / AO2 | ポンプ | 水を吸わない（逆回転）ときは2本を入れ替える |
| BIN1 / BIN2 / PWMB / BO1 / BO2 | 未接続 | B側は使わない |

### 電源モジュール

| 端子 | 現在の接続先 | ポンプ追加後の接続先 |
|---|---|---|
| 5V出力 | ESP32 5V | ESP32 5V ＋ TB6612FNG VM（ポンプが5V用の場合） |
| GND | ESP32 GND | 共通GND |

ポンプの定格が5V以外のときは、VMへの電源の取り方が変わる。ポンプの仕様が決まった段階で見直す。

### 電源

- USB給電だけで動く。
- 電源モジュールの5V出力をESP32の5Vピンにつなぐ場合、GNDも共通にする。
- **USBと電源モジュールの5Vを同時にESP32の5Vピンへつながない。** USBで書き込む・シリアルモニタを見るときは、5Vピンへの配線を外す。

```
[電源モジュール] ─ 5V出力 ──▶ ESP32 5Vピン
                 ─ GND    ──▶ ESP32 GND
```

### 電源モジュールのテスト手順

1. **書き込み**: USBでつないでファームを書き込み、スイッチでLEDが切り替わることを確認する。終わったらUSBを外す。
2. **出力電圧の確認**: ESP32につなぐ前に、電源モジュールの出力をテスターで測り、5V（4.8〜5.2V程度）であることを確かめる。可変式のモジュールは、ここで5.0Vに合わせる。
3. **接続**: 電源モジュールのOFFを確かめてから、5V出力をESP32の5Vピンへ、GNDをESP32のGNDへつなぐ。
4. **起動**: 電源モジュールをONにし、外付けLEDがゆっくり3回点滅し、その後、基板上のLEDが点滅し続けることを確認する。
5. **スイッチ操作**: タクトスイッチでLEDが切り替わることを確認する。
6. **電圧の確認（任意）**: 動作中にESP32の5Vピン、3.3VピンとGNDの間をテスターで測り、それぞれ約5V、約3.3Vであることを確かめる。

起動時に「速く10回」点滅する、または基板上のLEDの点滅が途中で止まる・最初からやり直す場合は、電源モジュールの出力電圧・電流容量・配線の接触を見直す。

## ビルドと書き込み

VS Codeで `esp32-pump.code-workspace` を開き、PlatformIOで `firmware` をビルド・書き込みする。

```bash
cd firmware
pio run -t upload
pio device monitor
```

## ファイル構成

| ファイル | 内容 |
|---|---|
| `firmware/src/config.h` | ピン割り当て、チャタリング対策の時間、点滅間隔 |
| `firmware/src/main.cpp` | タクトスイッチでLEDを切り替える。起動の理由と動作中であることをLEDで表す |
