## esp32-pump - ESP32からポンプを制御

ESP32-C3からポンプを制御するWebアプリ

現在は、タクトスイッチでポンプを運転・停止する動作確認用のサンプルファームウェアのみ。

## 動作確認サンプル

- 電源を入れた直後は、ポンプを止めた状態にする
- タクトスイッチを押すたびに、ポンプの運転・停止を切り替える
- 外付けLEDはポンプの運転中に点灯する
- 運転開始時は0.5秒かけて出力を上げる（ソフトスタート。起動時の電圧低下でESP32がリセットするのを防ぐ）
- 30秒運転すると自動で止まる（空回り・水のあふれ防止。`config.h` の `PUMP_MAX_RUN_MS` で変更、0で無効）
- 電源モジュールから給電するとシリアルモニタが使えないため、状態をLEDで表す

| 表示 | 意味 |
|---|---|
| 起動時、外付けLEDがゆっくり3回点滅 | 通常の起動 |
| 起動時、外付けLEDが速く10回点滅 | 電圧低下でリセットした（ブラウンアウト）。電源を見直す |
| 外付けLEDが点灯 | ポンプ運転中 |
| 基板上のLEDが0.5秒ごとに点滅 | プログラムが動いている |
| 基板上のLEDが点滅しない | 電源が来ていない、またはプログラムが止まっている |

## 構成

| 部位 | 部品 | 備考 |
|---|---|---|
| マイコン | ESP32-C3 Super Mini | PlatformIOのボード設定は `esp32-c3-devkitm-1` |
| モータードライバ | TB6612FNG モジュール | A側（AO1/AO2）だけを使う。連続1.2A／ピーク3.2A、VM 2.5〜13.5V |
| 電源 | 電源モジュール | 5V出力。ESP32とポンプ（VM）に供給する |
| ポンプ | DCポンプ | 連続1A以下のもの |
| スイッチ | タクトスイッチ | |
| LED | LED ＋ 330Ω抵抗 | |
| 抵抗（推奨） | 10kΩ | STBY–GND間のプルダウン。電源投入直後にポンプが一瞬回るのを防ぐ |
| コンデンサ（推奨） | 電解 100〜470µF、セラミック 0.1µF | ノイズ・電圧低下対策 |

## 配線

ピン番号を変えたときは `firmware/src/config.h` と合わせて直す。

### ESP32-C3 Super Mini

| 端子 | 接続先 | 備考 |
|---|---|---|
| 5V | 電源モジュールの5V出力 | USBと同時につながない |
| GND | 共通GND（電源モジュール、TB6612FNG、スイッチ、LED） | GNDはすべて共通にする |
| 3V3 | TB6612FNG VCC | TB6612FNGのロジック電源 |
| GPIO0 | — | 空き |
| GPIO1 | — | 空き |
| GPIO2 | — | 起動モードを決めるピンなので使わない |
| GPIO3 | タクトスイッチ（もう片側はGND） | 内部プルアップを使うので抵抗は不要 |
| GPIO4 | TB6612FNG AIN1 | ポンプの回転方向1 |
| GPIO5 | TB6612FNG AIN2 | ポンプの回転方向2 |
| GPIO6 | TB6612FNG PWMA | ポンプの出力（PWM 20kHz、10bit） |
| GPIO7 | 330Ω → LEDの長い足（短い足はGND） | ポンプ運転中に点灯 |
| GPIO8 | 基板上のLED（外部には何もつながない） | 動作中の点滅表示。起動モードを決めるピン |
| GPIO9 | — | BOOTボタン。起動モードを決めるピンなので使わない |
| GPIO10 | TB6612FNG STBY | LOWにするとポンプを切り離す。10kΩでGNDへプルダウンを推奨 |
| GPIO20 | — | 空き（UART RX） |
| GPIO21 | — | 空き（UART TX） |

GPIO18/19は基板内でUSB（書き込み・シリアル）に使われているため、端子には出ていない。

### TB6612FNG

| 端子 | 接続先 | 備考 |
|---|---|---|
| VM | 電源モジュールの5V出力 | ポンプ用の電源。VMとGNDの間、端子の近くに電解コンデンサを入れる |
| VCC | ESP32 3V3 | |
| GND | 共通GND | モジュールにGND端子が複数あれば、すべてつなぐ |
| AIN1 / AIN2 / PWMA | GPIO4 / GPIO5 / GPIO6 | |
| STBY | GPIO10 | 3.3Vに直結しない（直結するとポンプを止められない） |
| AO1 / AO2 | ポンプ | 水を吸わない（逆回転）ときは2本を入れ替えるか、`PUMP_INVERT` を true にする |
| BIN1 / BIN2 / PWMB / BO1 / BO2 | 未接続 | B側は使わない |

ポンプの端子間には0.1µFのセラミックコンデンサを入れる（ブラシのノイズ対策）。

### 電源モジュール

| 端子 | 接続先 |
|---|---|
| 5V出力 | ESP32 5V、TB6612FNG VM |
| GND | 共通GND |

```
[電源モジュール] ─ 5V出力 ─┬─▶ ESP32 5Vピン
                           └─▶ TB6612FNG VM ──(AO1/AO2)──▶ ポンプ
                 ─ GND ────────▶ 共通GND
```

- **USBと電源モジュールの5Vを同時にESP32の5Vピンへつながない。** USBで書き込む・シリアルモニタを見るときは、ESP32の5Vピンへの配線を外す（VMへの供給はそのままでよい）。
- ポンプの定格電圧より電源電圧が高いときは、`config.h` の `PUMP_DEFAULT_PERCENT` を下げて実効電圧を定格内に収める。
- ポンプの定格が5V以外のときは、VMへの電源の取り方を見直す。

### 電源モジュールのテスト手順（ポンプなし）

1. **書き込み**: USBでつないでファームを書き込む。終わったらUSBを外す。
2. **出力電圧の確認**: ESP32につなぐ前に、電源モジュールの出力をテスターで測り、5V（4.8〜5.2V程度）であることを確かめる。可変式のモジュールは、ここで5.0Vに合わせる。
3. **接続**: 電源モジュールのOFFを確かめてから、5V出力をESP32の5Vピンへ、GNDをESP32のGNDへつなぐ。
4. **起動**: 電源モジュールをONにし、外付けLEDがゆっくり3回点滅し、その後、基板上のLEDが点滅し続けることを確認する。
5. **スイッチ操作**: タクトスイッチで外付けLEDが切り替わることを確認する。
6. **電圧の確認（任意）**: 動作中にESP32の5Vピン、3.3VピンとGNDの間をテスターで測り、それぞれ約5V、約3.3Vであることを確かめる。

起動時に「速く10回」点滅する、または基板上のLEDの点滅が途中で止まる・最初からやり直す場合は、電源モジュールの出力電圧・電流容量・配線の接触を見直す。

## うまく動かないとき

| 症状 | 原因と対処 |
|---|---|
| 電源を入れるとポンプが回り、スイッチで止まらない | ポンプ制御の入っていない古いファームのままになっている。最新のファームを書き込む |
| 最新のファームでも、電源を入れるとポンプが回る | ポンプがAO1/AO2ではなく電源に直接つながっている、またはSTBYが3.3Vに直結されている。配線を確認する |
| 電源を入れた瞬間だけポンプが一瞬回る | ファームが動き出すまでの間、GPIOの状態が決まっていないため。STBYとGNDの間に10kΩを入れる |
| ポンプを動かすと「速く10回」点滅して再起動する | ポンプの起動電流で電圧が下がっている。VM–GND間に電解コンデンサを入れる、電源モジュールの電流容量を見直す |

## ビルドと書き込み

VS Codeで `esp32-pump.code-workspace` を開き、PlatformIOで `firmware` をビルド・書き込みする。

```bash
cd firmware
pio run -t upload
pio device monitor
```

## シリアルコマンド（115200bps）

| コマンド | 動作 |
|---|---|
| `ON` | ポンプを運転する |
| `OFF` | ポンプを止める |
| `P <0-100>` | 運転時の出力（%）を変える。運転中ならその出力へ徐々に変える |
| `?` | 状態（運転中/停止中、出力、スイッチ、自動停止までの時間）を表示する |

起動時には、起動の理由（電源投入、ブラウンアウトなど）も表示する。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `firmware/src/config.h` | ピン割り当て、出力・ソフトスタート・自動停止・点滅間隔などの設定 |
| `firmware/src/PumpDriver.h/.cpp` | TB6612FNGでポンプを回す（ソフトスタート付き） |
| `firmware/src/main.cpp` | タクトスイッチ・LED・シリアルコマンドの処理。起動の理由と動作中であることをLEDで表す |
