## esp32-pump - ESP32からポンプを制御

ESP32-C3からポンプを制御するWebアプリ

現在は、スイッチ、LED、ポンプの動作確認用のサンプルファームウェアのみ。

## 動作確認サンプル

- タクトスイッチを押すたびに、ポンプの運転・停止を切り替える
- 外付けLEDはポンプの運転中に点灯する
- 基板上のLED（GPIO8）は、動作中であることを示すため0.5秒ごとに点滅する
- 運転開始時は0.5秒かけて出力を上げる（ソフトスタート。起動時の電圧低下でESP32がリセットするのを防ぐ）
- 30秒運転すると自動で止まる（空回り・水のあふれ防止。`config.h` の `PUMP_MAX_RUN_MS` で変更、0で無効）

## 構成

| 部位 | 部品 | 備考 |
|---|---|---|
| マイコン | ESP32-C3 Super Mini | PlatformIOのボード設定は `esp32-c3-devkitm-1` |
| モータードライバ | TB6612FNG モジュール | A側（AO1/AO2）だけを使う。連続1.2A／ピーク3.2A、VM 2.5〜13.5V |
| 電源 | 電源モジュール | ポンプの定格電圧を出力できるもの（例: 5V） |
| ポンプ | DCポンプ | 連続1A以下のもの |
| スイッチ | タクトスイッチ | |
| LED | LED ＋ 330Ω抵抗 | |
| コンデンサ | 電解 100〜470µF、セラミック 0.1µF | ノイズ・電圧低下対策 |

## 配線

### ESP32-C3 Super Mini

| GPIO | 用途 | 接続先 |
|---|---|---|
| 3 | タクトスイッチ | スイッチの片側。もう片側はGND（内部プルアップを使うので抵抗は不要） |
| 4 | ポンプ方向1 | TB6612FNG AIN1 |
| 5 | ポンプ方向2 | TB6612FNG AIN2 |
| 6 | ポンプPWM | TB6612FNG PWMA（20kHz、10bit） |
| 7 | LED | 330Ω → LEDのアノード（長い足）。カソード（短い足）はGND |
| 8 | 基板上のLED | 外部回路はつながない |
| 10 | ポンプ有効 | TB6612FNG STBY（LOWでポンプを切り離す） |
| 2, 9 | （未使用） | 起動モードを決めるピンのため使わない |
| 18, 19 | （未使用） | USB（書き込み・シリアル） |

### TB6612FNG モジュール

| 端子 | 接続先 | 備考 |
|---|---|---|
| VM | 電源モジュールの出力＋ | ポンプ用の電源。端子のすぐ近くでGNDとの間に電解コンデンサを入れる |
| VCC | ESP32の3.3V | ロジック電源 |
| GND | 共通GND | |
| AIN1 / AIN2 / PWMA | GPIO4 / GPIO5 / GPIO6 | |
| STBY | GPIO10 | |
| AO1 / AO2 | ポンプ | 水を吸わない（逆回転）場合は配線を入れ替えるか、`PUMP_INVERT` を true にする |
| B側（BIN1/BIN2/PWMB/BO1/BO2） | 未接続 | |

ポンプの端子間には0.1µFのセラミックコンデンサを入れる（ブラシのノイズ対策）。

### 電源

```
[電源モジュール] ─ 出力＋ ─┬─▶ TB6612FNG VM ──▶ ポンプ
                           └─▶ ESP32 5Vピン（出力が5Vのときのみ）
                 ─ 出力− ──▶ 共通GND（ESP32 GND、TB6612FNG GND）
```

- 電源モジュールの出力が5Vなら、ESP32の5Vピンにも供給できる。5V以外（6V、12Vなど）のときは5Vピンにつながず、ESP32はUSBか別の5V電源から給電する。
- GNDは必ず共通にする。
- **USBと電源モジュールの5Vを同時にESP32の5Vピンへつながない。** USBで書き込む・シリアルモニタを見るときは、5Vピンへの配線を外す（VMへの供給はそのままでよい）。
- ポンプの定格電圧より電源電圧が高いときは、`config.h` の `PUMP_DEFAULT_PERCENT` を下げて実効電圧を定格内に収める。

## ビルドと書き込み

VS Codeで `esp32-pump.code-workspace` を開き、PlatformIOで `firmware` をビルド・書き込みする。

```bash
cd firmware
pio run -t upload
pio device monitor
```

## シリアルコマンド（115200bps）

| コマンド | 動作 |
|---|---|
| `ON` | ポンプを運転する |
| `OFF` | ポンプを止める |
| `P <0-100>` | 運転時の出力（%）を変える。運転中ならその出力へ徐々に変える |
| `?` | 状態（運転中/停止中、出力、スイッチ、自動停止までの時間）を表示する |

## ファイル構成

| ファイル | 内容 |
|---|---|
| `firmware/src/config.h` | ピン割り当て、出力・ソフトスタート・自動停止などの設定 |
| `firmware/src/PumpDriver.h/.cpp` | TB6612FNGでポンプを回す（ソフトスタート付き） |
| `firmware/src/main.cpp` | タクトスイッチ・LED・シリアルコマンドの処理 |
