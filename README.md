## esp32-pump - ESP32からポンプを制御

ESP32-C3からポンプを制御するWebアプリ

現在は、スイッチとLEDの動作確認用のサンプルファームウェアのみ（ポンプはまだつながない）。

## 動作確認サンプル

- タクトスイッチを押すたびに、外付けLEDの点灯・消灯を切り替える
- 切り替えたときは、シリアルモニタ（115200bps）に「LED: 点灯」「LED: 消灯」と表示する

## 構成

| 部位 | 部品 | 備考 |
|---|---|---|
| マイコン | ESP32-C3 Super Mini | PlatformIOのボード設定は `esp32-c3-devkitm-1` |
| モータードライバ | TB6612FNG モジュール | 今回は未使用（ポンプ制御で使う予定） |
| 電源 | 電源モジュール | ESP32へ5Vを供給する場合に使う。USB給電だけでも動く |
| スイッチ | タクトスイッチ | |
| LED | LED ＋ 330Ω抵抗 | |

## 配線

| GPIO | 用途 | 接続先 |
|---|---|---|
| 3 | タクトスイッチ | スイッチの片側。もう片側はGND（内部プルアップを使うので抵抗は不要） |
| 7 | LED | 330Ω → LEDのアノード（長い足）。カソード（短い足）はGND |
| 4, 5, 6, 10 | （空き） | ポンプ用のTB6612FNG（AIN1 / AIN2 / PWMA / STBY）で使う予定 |
| 2, 8, 9 | （未使用） | 起動モードを決めるピンのため使わない（8は基板上のLED） |
| 18, 19 | （未使用） | USB（書き込み・シリアル） |

### 電源

- USB給電だけで動く。
- 電源モジュールの5V出力をESP32の5Vピンにつなぐ場合、GNDも共通にする。
- **USBと電源モジュールの5Vを同時にESP32の5Vピンへつながない。** USBで書き込む・シリアルモニタを見るときは、5Vピンへの配線を外す。

## ビルドと書き込み

VS Codeで `esp32-pump.code-workspace` を開き、PlatformIOで `firmware` をビルド・書き込みする。

```bash
cd firmware
pio run -t upload
pio device monitor
```

## ファイル構成

| ファイル | 内容 |
|---|---|
| `firmware/src/config.h` | ピン割り当て、チャタリング対策の時間 |
| `firmware/src/main.cpp` | タクトスイッチでLEDの点灯・消灯を切り替える |
